# PRMS Reserves Verification with ML

An automated pipeline that consolidates oil & gas reserves reports from several subsidiaries,
calculates key SPE PRMS indicators and uses machine learning to flag suspicious discrepancies
between the company's internal estimates and the independent auditor's estimates.

> **All data in this repository is synthetic.** Field names and numbers are generated by
> `src/generate_synthetic_data.py`. The approach mirrors a production workflow I built at work;
> no corporate data or code is published here.

## The problem

Reserves audits across a group of subsidiaries arrive in inconsistent Excel and CSV layouts,
in different encodings and column names. Reviewers compare company vs auditor numbers field by
field, by hand. That is slow, and large gaps can be missed.

## What the pipeline does

```
raw reports (3 formats) ──► extract & normalize ──► KPIs (RRR, RLI, gaps)
                                                        │
          Power BI / Excel report ◄── explanations ◄── anomaly detection
                                     (template or LLM)   (rules + Isolation Forest)
```

1. **Extract & normalize.** Reads a wide Excel table, a long Excel table and a cp1251 CSV with
   Russian headers and a title block, and maps them to one tidy schema.
2. **KPIs.** Reserve Replacement Ratio (RRR), Reserve Life Index (RLI), company vs auditor gap,
   year-over-year change, for 1P / 2P / 3P.
3. **Anomaly detection.** A transparent rule (gap above 15%) combined with an Isolation Forest
   on gap, YoY change and implied RRR, so unusual combinations are caught even below the threshold.
4. **Explanations.** Each flagged record gets a short reviewer note. If `ANTHROPIC_API_KEY` is set,
   an LLM writes the note in the voice of a reserves engineer; otherwise a template is used.
5. **Report.** Excel workbook (summary, flagged records, full data), a Power BI ready CSV and charts.

## Results on the synthetic dataset

Four anomalies were injected into 45 records (15 fields, 3 companies).
The pipeline flagged 5 records: **all 4 injected anomalies plus 1 borderline case**
(Field_C4 3P), which the reviewer can dismiss. This is intended: the tool narrows the review
to a short list, and the engineer makes the final call.

## Run it

```bash
pip install -r requirements.txt
python src/generate_synthetic_data.py
python src/pipeline.py
# optional: export ANTHROPIC_API_KEY=... to get LLM-written explanations
```

Outputs appear in `output/`.
